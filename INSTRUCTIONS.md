# Як виконати практичну роботу покроково

1. Відкрий GitHub і зроби fork репозиторію `training-website` разом з усіма гілками.
2. Перейди в гілку `lesson-1`.
3. Відкрий `Code > Codespaces > Create codespace on lesson-1`.
4. Встанови розширення **Live Server**.
5. Заміні файли у своєму проєкті файлами з цього архіву.
6. Відкрий `index.html` через Live Server.
7. Перевір сторінки: головна, зовнішній вигляд, харчування, ареал, галерея.
8. На сторінці галереї перевір Bootstrap-карусель.
9. На сторінці ареалу перевір акордеон і зміст збоку.
10. Відкрий Developer Tools через `Inspect` і зроби скріншоти кожної сторінки.
11. У Source Control введи повідомлення коміту, наприклад: `Практична робота 1: сайт про білого ведмедя`.
12. Натисни `Commit`, потім `Sync Changes`.
13. У Moodle здай посилання на fork-репозиторій і скріншоти сторінок.


## Фотографії користувача
