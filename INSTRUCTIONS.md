# Як виконати практичну роботу №2 покроково

## Тема
React-додаток про білого ведмедя. Додаткова інформація: `eatenFish` — кількість зʼїденої риби за день, кг.

## Кроки виконання

1. Відкрий свій fork репозиторія `training-website` на GitHub.
2. Створи або відкрий гілку `lesson-2`.
3. Натисни `Code > Codespaces > Create codespace on lesson-2`.
4. Дочекайся відкриття Codespaces.
5. Завантаж файли з цього архіву у проєкт, замінивши старі файли.
6. У терміналі виконай команду:

```bash
npm install
```

7. Запусти React-додаток:

```bash
npm start
```

8. Відкрий сайт у браузері через кнопку `Open in Browser` або вкладку `Ports`.
9. Перевір сторінки:
   - головна;
   - зовнішній вигляд;
   - харчування;
   - ареал;
   - фотографії;
   - результати пошуку.
10. На сторінці `Харчування` зміни число в полі `eatenFish` і перевір, що React перераховує кількість риби за день, тиждень і 30 днів.
11. У пошуку введи вдалий запит, наприклад `ведмідь` або `eatenFish`.
12. У пошуку введи невдалий запит, наприклад `слон`.
13. Відкрий Developer Tools через `Inspect` і зроби скріншоти кожної сторінки.
14. Натисни зліва `Source Control`.
15. Введи повідомлення коміту, наприклад:

```text
Практична робота 2 — React сайт про білого ведмедя
```

16. Натисни `Commit`, потім `Sync Changes`.
17. У Moodle здай посилання на GitHub-репозиторій і скріншоти сторінок.
